These estimates precede implementation and measurement. S is the starter single agent, M is the proposed split, and S-plus is a single agent budgeted at M's mean token spend on each task.

| Task kind | Predicted mean tokens, M / S | Predicted passes, S | Predicted passes, M | Will S-plus do as well as M? |
|---|---:|---:|---:|---|
| Single issue | 1.4× | 16/18 | 15/18 | Yes, about 16/18. |
| Batch of five | 1.2× | 3/6 | 4/6 | Yes, about 4/6. |

On one issue the writer needs the investigator's finding before it can act. An incomplete handoff can lose a file or confuse an unresolved search with a finding of no responsible file. I expect one additional failed run from that risk.

On a batch I expect fresh issue contexts to reduce mix-ups enough to pass one additional whole batch. S-plus can also start fresh per issue. I expect M's clearest batch advantage to be shorter elapsed time if independent investigations overlap. A batch earns one pass only when all five issues pass.
